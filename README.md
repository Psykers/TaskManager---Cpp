# TaskManager in C++

EN: A simple command-line task manager writen in C++.

PL: Prosty menedzer zadan dzialajacy w wierszu polecen, napisany w jezyku C++.

## Features

EN: 

-Add tasks

-Display tasks

-Mark tasks as completed

-Delete tasks

-Save tasks to a file


PL:

-Dodawanie zadan

-Wyswietlanie zadan

-Oznaczanie zadan jako ukonczone

-Usuwanie zadan

-Zapisywanie zadan do pliku
